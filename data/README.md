# Data

Datasets are **never committed**. This folder is gitignored except this README and
`MANIFEST.sha256` (the SHA-256 checksum of every raw file).

## CIC-IDS2017 (primary dataset)

| Field | Value |
|---|---|
| Publisher | Canadian Institute for Cybersecurity (CIC), University of New Brunswick |
| Version | Original release, **GeneratedLabelledFlows / TrafficLabelling** CSVs (ADR-0007, proposed) |
| Official page | PENDING: DATA-03 records the exact URL used and the date |
| Citation | PENDING: DATA-03 records the citation requested by the publisher |
| Why TrafficLabelling? | Only these CSVs contain per-flow timestamps, which the chronological split needs. The "MachineLearningCVE" CSVs do not |

data/

The file names above are the expected originals and must be **verified on download**
(DATA-02). If they differ, update `configs/data/cicids2017.yaml`, not the files.

Raw files are read-only. Never edit them; every derived file is regenerated by code.
